# My Portfolio Website

This is a personal portfolio website created using **only HTML and CSS**.  
It showcases my skills, projects, and contact information in a clean and professional layout.

## Features
- Fully responsive design
- Modern UI/UX design principles
- Sections include:
  - Home
  - Blog
  - Pages
  - About Me
  - Projects
  - Contact Information
- Smooth layout with proper alignment and spacing
- Social media links in the footer

## Technologies Used
- HTML5
- CSS

## How to View
1. Clone or download this repository.
2. Open the `index.html` file in any web browser.
